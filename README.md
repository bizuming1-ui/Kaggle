# \# ViiTorVoice Kaggle 克隆语音系统开发备忘录

# 

# \## 项目目标

# 

# 开发基于 Kaggle 双 T4 GPU 的实时高质量语音克隆系统。

# 

# 核心目标：

# 

# \- 输入文字

# \- DeepSeek / LLM 流式生成文本

# \- Qwen3-TTS-1.7B 进行声音克隆

# \- 一边生成克隆语音

# \- 一边实时播放

# \- 保证长期稳定运行

# 

# 

# \---

# 

# \# 一、总体技术路线

# 

# \## AI 层

# 

# Python + PyTorch

# 

# 负责：

# 

# \- LLM 输出处理

# \- 文本切片

# \- TTS 调度

# \- 推理优化

# \- 模型管理

# 

# 

# \## GPU 加速层

# 

# CUDA / PyTorch

# 

# 负责：

# 

# \- CUDA Graph

# \- TensorRT / Torch Compile 优化

# \- 双 T4 调度

# \- 显存管理

# 

# 

# \## 实时音频层

# 

# Rust Runtime

# 

# 负责：

# 

# \- PCM 音频缓冲

# \- 无锁队列

# \- 动态水位控制

# \- underrun predictor

# \- 长时间稳定播放

# 

# 

# \## 浏览器播放层

# 

# TypeScript / JavaScript

# 

# 负责：

# 

# \- WebAudio API

# \- 自动播放

# \- 连续播放

# \- GAP 消除

# 

# 

# \---

# 

# \# 二、必须实现功能

# 

# \## 1. 流式语音生成

# 

# 要求：

# 

# LLM 输出:

# 

# ↓

# 

# segmenter 分段:

# 

# ↓

# 

# TTS:

# 

# ↓

# 

# PCM:

# 

# ↓

# 

# 播放

# 

# 

# 不能出现：

# 

# 生成 → 停止 → 生成 → 停止

# 

# 

# 必须连续输出。

# 

# 

# \---

#

# 

# 目标：

# 

# \- 保留音色

# \- 保留说话风格

# \- 保留韵律

# \- 增加呼吸感

# \- 提升真人感

# 

# 

# 优化方向：

# 

# \- Voice Clone Prompt Cache

# \- Reference Audio 优化

# \- Prompt embedding 缓存

# \- 推理加速
