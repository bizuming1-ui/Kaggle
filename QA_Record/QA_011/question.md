# QA-011

## 问题

确定Qwen3-TTS-1.7B真人感音质优化方向。


## 用户选择

A


## 确认方案

采用参考音频质量 + Prompt工程 + 韵律控制方案。


## 技术流程

高质量参考音频

↓

Speaker Embedding优化

↓

Voice Clone Prompt Cache

↓

文本韵律标记

↓

Qwen3-TTS-1.7B生成


## 优化目标

实现：

- 保留原始音色；
- 保留说话风格；
- 保留语气变化；
- 增加自然停顿；
- 增加呼吸感；
- 提高真人感。


## 技术原因

相比直接修改模型参数：

该方案：

1.

风险更低。

2.

容易测试。

3.

不会破坏模型能力。

4.

适合实时系统。

- Reference Audio质量检测；
- Speaker Embedding测试；
- Prompt Cache测试；
- 韵律控制测试。


## 验证标准

必须比较：

- 原始生成效果；
- 优化后效果；
- 音色一致性；
- 长文本稳定性。
