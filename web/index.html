03 / Launchpad

复制，粘贴，
就跑起来了。

这一页就是你的部署说明书。下面每一格都可以直接复制进 Kaggle Notebook； 也可以直接下载那个单文件部署包，一次性带走上游全部源码。

🌐 浏览器模拟器

不上 Kaggle 也能先看效果：模拟器页面与 Kaggle 运行的网站同一套页面源码， 内置部署态数据（双 T4、克隆音色、延迟指标），在浏览器里直接打开即可交互。 模拟器里的「复制」给出的就是真实可运行的 yuyinkelong 部署包，粘进 Kaggle 单元格即跑。

▶ 打开网站模拟器
1

新建 Notebook 并开启 GPU

右侧 → Add New → Notebook。右上角 ⚙ → Accelerator → GPU T4 ×2， Internet → On。这决定我们能否跑满双卡并行。

2

添加密钥（可选但强烈建议）

右上角 ⚙ → Secrets → Add Secret：DEEPSEEK_API_KEY、 HF_TOKEN。没有 LLM 密钥也能用，只是无法进行语音对话。

3

粘贴下面这一格并运行

它会自解压全部源码、按 CUDA 版本装依赖（不破坏预装的 torch）、 预下载模型、编译 Go 网关与 Rust 运行时，然后拉起服务并给出公网地址。

4

打开控制台

运行结束后 Notebook 输出里的 trycloudflare 链接就是控制台。 首次运行需要下载 6.7 GB 模型，请耐心等待。
